# hxwl-12 督导排班与危机随访交接台

由个案记录扩展：个案登记风险、随访截止、咨询师、督导与会谈室，排期整笔判定、冻结留痕，改派走交接单。

## 技术栈

React + Vite + TypeScript + CSS

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5112

## 业务规则

- 人员时段重叠（咨询师/督导）、高风险个案登记后 24 小时内无督导接单、会谈室冲突：整笔拒绝，原计划保留
- 高风险个案督导未接单：不得完成会谈
- 改派先建交接单：督导确认前原咨询师不释放；确认后未完成随访随交接承接
- 排期提交即冻结：更正必须留原因并生成版本
- 每次判定通过后整体落库 localStorage，刷新后个案、排班、交接、版本一致

## 代码结构

- `src/data/` 数据层：类型定义与示例种子
- `src/domain/` 判定层：纯函数规则（冲突检测、24 小时接单、完成拦截、交接、留痕更正）
- `src/storage/` 存储层：localStorage 持久化与重置
- `src/App.tsx` 界面装配
